# 无名桌宠 v0.1（安卓源代码）

使用用户提供的透明 PNG 精灵图制作的安卓全局悬浮桌宠原型。

## 当前功能
- 全局悬浮显示、手指拖动
- 6 帧待机循环
- 点击切换为 8 帧行走动画，再点切回待机
- 主界面启动/收起

## 构建 APK
1. 使用 Android Studio 打开本文件夹（项目根目录）。
2. 等待 Gradle 同步并安装 Android SDK 35（如提示）。
3. 菜单 Build > Build Bundle(s) / APK(s) > Build APK(s)。
4. 将生成的 `app/build/outputs/apk/debug/app-debug.apk` 安装到安卓手机。
5. 打开“无名桌宠”，点击“启动无名”，按提示授权“显示在其他应用上层”，返回再点一次启动。

## 说明
- 本交付为可编辑的 Android Studio **源代码项目**，不是已编译 APK；尚未在实体设备上验证。
- 第一版暂不包含自动走动、开机自启、更多方向动作和前台服务保活。
- 部分安卓系统会限制后台 Service；后续可加入前台服务及通知，优化稳定性。
- 当前动作帧按提供的精灵图网格裁剪，可能需要根据手机显示效果微调裁切范围。
